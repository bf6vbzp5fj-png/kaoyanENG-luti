# 考研英语录题格式转换工具（纯前端版）

考研英语录题格式转换工具的**纯前端版本**，所有逻辑在浏览器中运行，不需要后端服务器。

## ✨ 特性

- 🖥️ **纯前端**：双击 `index.html` 即可使用，无需安装、无需服务器
- 📝 **7 个标签页**：整卷导入、完形填空、阅读理解、新题型、翻译、小作文、大作文
- 🤖 **智能拆分**：粘贴整卷文本，自动识别并拆分到各题型
- 👀 **实时预览**：输入即时渲染，所见即所得
- 📋 **富文本复制**：一键复制带格式内容，可直接粘贴到 Word
- 📄 **Word 导出**：使用 docx.js 在浏览器中生成 .docx 文件并下载
- 🎯 **格式规范**：
  - 无标签行
  - 选项逐行换行
  - 【1】单独占一行
  - 完形空位数字自动下划线
  - 翻译划线句下划线
  - 新题型选项复用
  - 英一/英二切换
  - 标点规范
  - 支持 `__内容__` 下划线、`**内容**` 加粗 标记语法

## 🚀 使用方法

### 方式一：直接打开（推荐）

直接双击 `index.html` 文件，在浏览器中打开即可使用。

### 方式二：本地服务器

```bash
# Python 3
python -m http.server 8000

# Node.js
npx serve .
```

然后访问 `http://localhost:8000`

### 方式三：部署到静态托管

可直接上传到以下平台部署：
- GitHub Pages
- Netlify
- Vercel
- Cloudflare Pages
- 任何静态文件托管服务

## 🔧 技术栈

- 原生 HTML + CSS + JavaScript（无框架依赖）
- [docx.js](https://docx.js.org/) - 前端生成 Word 文档
- [file-saver.js](https://github.com/eligrey/FileSaver.js/) - 浏览器文件下载
- 所有依赖通过 CDN 引入，无需 npm 安装

## 📝 使用说明

### 整卷导入

1. 将试题原文粘贴到左侧文本框
2. 将答案解析粘贴到右侧文本框（可选）
3. 点击「智能拆分」按钮
4. 系统会自动识别各题型并填充到对应标签页
5. 点击「导出整卷Word」可一键导出完整试卷

### 各题型编辑

每个题型标签页都分为左右两栏：
- **左侧**：编辑区，输入题目内容、选项、答案、解析等
- **右侧**：实时预览区，展示格式化后的效果

支持操作：
- 📋 复制：复制富文本内容，可直接粘贴到 Word
- 📥 下载Word：生成并下载 .docx 文件
- 🔧 规范标点：一键规范中英文标点

### 标记语法

在文本中可以使用以下标记实现格式效果：

| 标记 | 效果 | 示例 |
|------|------|------|
| `__内容__` | 下划线 | `__重点词汇__` |
| `**内容**` | 加粗 | `**正确答案**` |

这些标记在预览、复制和 Word 导出中都会正确渲染。

## 🔄 与 Flask 版本的区别

| 特性 | Flask 版 | 纯前端版 |
|------|----------|----------|
| 运行方式 | 需要 Python 后端 | 纯浏览器运行 |
| 部署 | 需要服务器 | 静态文件即可 |
| Word生成 | python-docx (后端) | docx.js (前端) |
| 整卷解析 | Python 后端 | JavaScript 前端 |
| 数据安全 | 上传到服务器 | 全部本地处理 |
